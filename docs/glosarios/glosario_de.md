## Notas de estilo
- Números, fórmulas, unidades (kg CO₂, R²=0.89, <6%, litros, TWh) → **NUNCA se traducen ni reformatean**.
- Nombres propios de autores/estudios citados (Strubell et al., Patterson, Luccioni, IEA, Nature Comp. Sci.) → **se mantienen exactamente igual**.
- Rutas de archivo (`../assets/...`), clases CSS, IDs → **se mantienen intactas**.
- Nota de traducción a insertar en cada página (excepto ES/EN): *"Übersetzung des geprüften spanischen/englischen Originals. Im Falle von Abweichungen ist das Original maßgeblich."*
- Alemán usa sustantivos compuestos (Kompositum) donde el español usa frases con preposición — p. ej. "Huella de Carbono" → "CO2-Fußabdruck" (una sola palabra), no "CO2 Fußabdruck" con espacio.
- Los sustantivos se escriben siempre con mayúscula inicial (regla ortográfica alemana), independientemente del uso en el español fuente.
