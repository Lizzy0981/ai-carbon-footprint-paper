## Notas de estilo
- Números, fórmulas, unidades (kg CO₂, R²=0.89, <6%, litros, TWh) → **NUNCA se traducen ni reformatean**.
- Nombres propios de autores/estudios citados (Strubell et al., Patterson, Luccioni, IEA, Nature Comp. Sci.) → **se mantienen exactamente igual**.
- Rutas de archivo (`../assets/...`), clases CSS, IDs → **se mantienen intactas**.
- Nota de traducción a insertar en cada página (excepto ES/EN): *"Terjemahan dari naskah asli berbahasa Spanyol/Inggris yang telah diverifikasi. Jika terdapat perbedaan, naskah asli yang berlaku."*
- Los números grandes usan el punto como separador de miles en indonesio (700.000, no 700,000 como en inglés) — convención inversa al inglés/español latinoamericano.
- El indonesio no tiene formas plurales gramaticales obligatorias (p. ej. "modelo" y "modelos" pueden ser ambos "model"); se prioriza claridad de contexto sobre marcado morfológico.
- Prefijos ISO alternativos: el código de idioma "id" es el actual (ISO 639-1); el código legado "in" aún aparece en algunos navegadores antiguos — se contempló en el JS de detección del index raíz.
