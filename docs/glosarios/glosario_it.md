## Notas de estilo
- Números, fórmulas, unidades (kg CO₂, R²=0.89, <6%, litros, TWh) → **NUNCA se traducen ni reformatean**.
- Nombres propios de autores/estudios citados (Strubell et al., Patterson, Luccioni, IEA, Nature Comp. Sci.) → **se mantienen exactamente igual**.
- Rutas de archivo (`../assets/...`), clases CSS, IDs → **se mantienen intactas**.
- Nota de traducción a insertar en cada página (excepto ES/EN): *"Traduzione dell'originale spagnolo/inglese verificato. In caso di discrepanze, prevale l'originale."*
- Apóstrofos en italiano (dell', all', l', un') requieren escape correcto (`\'`) al insertarse dentro de strings JavaScript entre comillas simples — error detectado y corregido durante este proyecto.
- "Datacenter" se usa como préstamo directo en italiano técnico (no se traduce a "centro dati" en el uso corriente del sector).
